# Food Delivery Web Application

## Project Overview

The Food Delivery Web Application is a web-based application developed using Python and Flask. It allows users to browse available restaurants, view restaurant menus, and add food items to a shopping cart.

The application also provides backend functionality for restaurant and menu management through admin operations and REST APIs.

## Features

### User Features

- View available restaurants
- View restaurant locations
- Browse restaurant menus
- View food item prices
- Add food items to the shopping cart
- Calculate the total cart amount

### Admin Features

- Add new restaurants
- Add menu items for restaurants
- Manage restaurant and menu information through backend operations

### REST API

- Retrieve restaurant information using REST API
- Return restaurant data in JSON format

## Technologies Used

- HTML
- CSS
- JavaScript
- Python
- Flask
- SQLite
- REST APIs
